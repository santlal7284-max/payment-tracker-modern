# Payment Tracker Web App

A modern finance dashboard to track School Fees, Credit Card Bills, and SIP Payments.

## How to Use
1. Upload all files to your GitHub repository.
2. Go to Settings → Pages → Branch: main → Folder: /root.
3. Save and get your live URL: https://username.github.io/payment-tracker-modern/.

## Features
- Modern gradient UI
- Emoji headers
- Responsive design
- Works on all devices
